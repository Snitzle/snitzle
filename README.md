# Hi, I'm Craig

I'm a full-stack developer based in Lincoln, UK. I build web and mobile products with Laravel, Vue, TypeScript, and React Native.

I enjoy working across the whole product: shaping an idea, designing the underlying systems, building the interface, and making sure the finished experience is clear and dependable. Accessibility is a big part of how I approach that work, not something I leave until the end.

Most of my recent engineering work is in private repositories. These are the two projects I'm currently focused on:

## Spicy Brain

[Spicy Brain](https://spicybrain.help) is a life-management app built around reminders, tasks, and the everyday responsibilities that are easy to lose track of. It uses Laravel and Vue on the web, with recurring schedules, notification delivery, and integrations such as Discord and Telegram.

The aim is simple: reduce cognitive load and give people flexible tools that work with their routines rather than against them.

## Spicy Brain Mobile

SpicyBrain Mobile is the Expo and React Native companion app. It brings reminder management, recurring series, quiet hours, account settings, integrations, and native push notifications to iOS and Android.

I'm building it with TypeScript, Expo Router, TanStack Query, secure token storage, native Storybook, and an accessibility-focused component system.

You can read more about what I'm building and the decisions behind it at [snitzle.github.io](https://snitzle.github.io/), or connect with me on [LinkedIn](https://www.linkedin.com/in/craig-william-jones/).
